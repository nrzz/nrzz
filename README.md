## Flagship

[![Sentinel](https://img.shields.io/badge/Sentinel-observability-0A7ACA?style=flat-square&logo=dotnet&logoColor=white)](https://github.com/nrzz/Sentinel)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](https://github.com/nrzz/Sentinel/blob/main/LICENSE)
[![.NET](https://img.shields.io/badge/.NET-10-512BD4?style=flat-square&logo=dotnet&logoColor=white)](https://github.com/nrzz/Sentinel)

**[Sentinel](https://github.com/nrzz/Sentinel)** — AI-native self-hosted observability for logs, metrics, traces, alerts, and incidents.
One deployment instead of five tools: OpenTelemetry ingestion, ClickHouse-backed storage, PromQL-style metrics, alert rules with escalation, and built-in AI root-cause investigation.

[![EventMesh](https://img.shields.io/badge/EventMesh-messaging-0A7ACA?style=flat-square&logo=dotnet&logoColor=white)](https://github.com/nrzz/EventMesh)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](https://github.com/nrzz/EventMesh/blob/main/LICENSE)
[![Build](https://img.shields.io/github/actions/workflow/status/nrzz/EventMesh/ci.yml?branch=main&label=build&style=flat-square)](https://github.com/nrzz/EventMesh/actions/workflows/ci.yml)
[![.NET](https://img.shields.io/badge/.NET-10-512BD4?style=flat-square&logo=dotnet&logoColor=white)](https://github.com/nrzz/EventMesh)

**[EventMesh](https://github.com/nrzz/EventMesh)** — Universal broker-agnostic messaging platform for .NET.
One API over Kafka, RabbitMQ, NATS, Redis Streams, AWS SQS, Azure Service Bus and Google Pub/Sub, with CloudEvents, outbox and saga patterns, and OpenTelemetry built in.

## Collaborate

Both flagship projects are at the stage where outside eyes change the most: a bug report from a real deployment, a broker you need that EventMesh does not cover yet, a dashboard that Sentinel should ship by default.

- Run self-hosted observability or event-driven .NET services? Tell me what is missing in [Sentinel discussions](https://github.com/nrzz/Sentinel/discussions) or [EventMesh discussions](https://github.com/nrzz/EventMesh/discussions).
- Want to contribute? Start with the [contributing guide](https://github.com/nrzz/Sentinel/blob/main/CONTRIBUTING.md) and the [roadmap](https://github.com/nrzz/Sentinel/blob/main/ROADMAP.md), then open an issue so we can scope it together.
- Found either project useful? A star helps other people find it, and following keeps you posted on releases.
